# Link Ahead

Link to scheduled or draft WordPress posts today. The link stays plain text until the target is published, then it turns into a real link on its own.

- Block editor format "Link Ahead" with a search for scheduled posts and drafts
- `[link_ahead id="123"]text[/link_ahead]` shortcode for the classic editor
- Report under Tools > Link Ahead
- Polylang and WPML: the link follows the translation in the reader's language
- Purges the page cache of linking posts when a target is published or unpublished (LiteSpeed Cache, Cache Enabler, WP Super Cache, W3 Total Cache, WP Rocket, WP Fastest Cache)

Requires WordPress 6.5 and PHP 7.4. Details in [readme.txt](readme.txt).
